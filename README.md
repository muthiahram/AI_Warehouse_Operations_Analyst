# AI-Powered Warehouse Operations Analyst

## Project Overview
Developed an AI-powered warehouse operations analyst to demonstrate how Generative AI, Machine Learning and Python can support predictive and data-driven warehouse operations.

## Technologies Used
- Python
- Google Colab
- Gemini API
- Pandas
- Scikit-learn
- Machine Learning
- Retrieval-Augmented Generation (RAG)

## Key Features
1. SKU inventory analysis
2. Predictive replenishment recommendations
3. Stockout risk identification
4. Demand forecasting using Random Forest
5. AI agent with selective tool calling and orchestration
6. FDS document retrieval and business-rule validation
7. Conversational memory
8. Historical warehouse observation and recurring risk detection

## Business Objective
Demonstrate how AI can assist warehouse functional teams in identifying inventory risks, analyzing replenishment requirements, forecasting demand and generating actionable operational recommendations.

## Disclaimer
Illustrative portfolio project using sample warehouse data. AI recommendations are decision-support outputs, not executed WMS transactions.
